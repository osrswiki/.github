# osrswiki

Unofficial phone apps for [oldschool.runescape.wiki](https://oldschool.runescape.wiki) — a polished reader with search, comfortable articles, offline pages, and an in-app world map. Not affiliated with Jagex Ltd. or the OSRS Wiki administration.

- [Android](https://github.com/osrswiki/osrswiki-android)
- [iOS](https://github.com/osrswiki/osrswiki-ios)
- [Privacy policy](https://osrswiki.github.io/osrswiki-privacy-policy/)
