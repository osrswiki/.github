# osrswiki

Unofficial fan-made phone readers for [oldschool.runescape.wiki](https://oldschool.runescape.wiki) — dedicated Android and iOS apps with search, readable articles, offline pages, and an in-app world map. Not affiliated with Jagex Ltd. or the OSRS Wiki administration.

- [Android](https://github.com/osrswiki/osrswiki-android)
- [iOS](https://github.com/osrswiki/osrswiki-ios)
- [Privacy policy](https://osrswiki.github.io/osrswiki-privacy-policy/)
